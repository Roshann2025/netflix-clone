 Netflix Clone (Static Website)

A static, responsive Netflix Clone built using HTML and CSS only (no JavaScript, no frameworks).
The goal of this project is to replicate the look and feel of Netflix’s UI, including navigation, banners, and movie listings, while keeping the structure clean and responsive for both desktop and mobile screens.

 Features

Responsive Design – Works on desktop, tablet, and mobile.

Navigation Bar – Logo, links, and sign-in button.

Hero Banner – Large featured background with overlay text and CTA button.

Movie Sections – Rows of movie posters styled like Netflix.

Hover Effects – Smooth animations for better user experience.

Footer – Simple Netflix-style footer with useful links.

 Tech Stack

HTML5 – Structure of the page

CSS3 – Styling, layout (Flexbox & Grid), responsiveness
